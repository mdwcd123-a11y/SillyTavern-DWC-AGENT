# Changelog / 更新记录

## V1.0 — 2026-11-01

### 中文

- 首次公开发布，名称为 Sillytavern DWC AGENT V1.0，版本号 1.0.0。
- 基于既有本地原型整理；保留逐角色工具循环、版本化记忆与有限格式校验。
- 同时提供前端扩展和本地后端插件，中英文安装与使用说明。
- 测试改为自包含合成数据，不读取个人预设或聊天。
- 明确公开现有兼容性限制；没有宣称已完成 MCP、后台自治或通用语义审稿。

### English

- Initial public release: Sillytavern DWC AGENT V1.0, package version 1.0.0.
- Packages the existing local prototype with per-character tool loops, versioned memory and limited output validation.
- Includes the frontend, local backend and bilingual documentation.
- Makes tests self-contained with synthetic fixtures; no personal presets or chats are read.
- Documents existing compatibility limitations. MCP, background autonomy and general semantic review are not implemented.
